# 0x424460 FindGoodDest(ent_id, x_px, y_px) -> packed (tileY<<16 | tileX)

[O] Finds a free tile near a requested destination.
1. dest tile = px>>5. Direction from dest toward the unit's current tile: sign(dx), sign(dy) -> index (sx+1)+(sy+1)*3 (0..8) -> table 0x4b5ed0 -> direction 0..7 (or -1 for same tile: returns dest unchanged) -> step (dx,dy) from tables 0x4b9e48/0x4b9e68 clamped to -1..1.
2. Step from dest toward the unit, up to 30 tiles, until a tile is free: terrain grid 0x8352f0 == 1 and occupancy 0x6d3920 == 0. Stops (returns original dest) when leaving the 0..0x7f map or after 30 steps.
3. Returns the first free tile found. Callers shift both halves left by 5 to get pixels.
Callers: 0x423710, 0x423f70.
