int RemapSpritePalette(void* spriteSet). Returns its arg. Skips if [0x5474a4]==0. [O]
Walks an RLE sprite container (offset table at base, count at [base + [0xa133c0]-4], i.e. last dword of the loaded file). For each sprite, rewrites each run's pixels from the file palette to the screen palette: rgb = [0x66cd44][idx*3..]; if [0x4aebe8]==1 averages each pair of adjacent pixels (halves width, 50% blend/downscale) ; new index = LUT[0xaa210c][(r*64+g)*64+b] (6-bit RGB cube -> index). Rewrites run length fields.
Used right after LoadFile (0x4081a0) for every graphic in the loader 0x40f2d0.
Reimpl: palette remap + optional 2x horizontal blend of RLE sprites.
