# 0x423f70 VehicleOrdersInterrupt(ent_id, cmd, a, target_ent, x_px, y_px)

Same argument shape as 0x423710 but gives an order that interrupts the current task and remembers it. [O code, I meaning]
- Preconditions: owner valid and != 99, alive, type != 0, and ENT+0x82 (0x67fe92, "saved mode") == -1 (nothing already saved); cmd 2 needs an attacker-type unit; target ent must be alive.
- Network mode (DAT_0071667c==1): queues record kind 7; else:
- cmd 7 -> ENT+0x64 = 7, else ENT+0x78 = cmd.
- Destination: if tile not free and unit not docked, FindGoodDest (0x424460).
- Writes new order (+0x7e a, +0x80 target, +0x7a x, +0x7c y, +0x8e=0, +0x90=1) and SAVES the previous one: +0x82 = current mode (+0x62; if mode 6 then +0x64), +0x88/+0x8a = old target (+0x46/+0x48), +0x84/+0x86 = old move target (+0x40/+0x42). Releases path slot +0xd6.
- If owner is AI (> H) and type table +0x64 (0x4c0874) != 0: cmd 1 -> ENT+0x6e = 5, cmd 2 -> ENT+0x6e = 8 (AI sub-mode) [?].
Used by AI tick case 7: (ent, 2, -1, ENT+0xa0 attacker, -1, -1) = attack whoever last attacked me, resume old task later [I].
