# 0x46b820 AI_AddOrMergeGuardPoint(short x_px, short y_px, int life)

[O] Records "an area needing guarding" in the global guard-point table GP (0x666620, 50 entries, stride 0x20).
1. Scan slots from 0. Stop at the first free slot (GP+8 == 0).
2. For each used slot before that: if |x - GP.x| < 0xa0 and |y - GP.y| < 0xa0 (5 tiles) -> MERGE: GP+8 = life, GP+0x1c = life (refresh), log "AI Merging new guard point." (only if 0x4b8b20==1), return.
3. Else if a free slot was found: GP.x = x, GP.y = y, GP+8 = life; log "AI Setting new guard point."  (GP+0x1c NOT set here; merge sets it.) Table full -> dropped silently.
Callers: 0x46bec0 loop A: x,y = unit position (obj.x>>16, obj.y>>16 px), life = ((f18/f24 as 16.16) & ~0xff) * 0x28 >> 16 [O].
Quirk [O]: the merge scan stops at the first free slot, so after pruning leaves a hole, later slots are never merged into; duplicates near an existing later point are possible.
GP table is global (shared by all AI players) [O].
