# 0x468600 AI_ScoreSurroundings(short p, x, y, UNIT* n)
[O] zero n+0x08, +0x14,+0x18,+0x1c,+0x20,+0x24,+0x28. For every unit node (list B) of every player 1..N whose ent+0x688 & 0x10000 == 0: d = Dist(x,y, ent tile).
band = 3 if d*0x20 < (short)(ent+0x92) (weapon range [?]); else d<5 -> 1; d<7 -> 2; d<10 -> 3; else 0.
Add obj.f2c cumulatively to bands 1..band: if obj owner == p: n+0x20 (band>=1), n+0x24 (>=2), n+0x28 (>=3) = FRIENDLY strength; else n+0x14,+0x18,+0x1c = ENEMY strength (<5, <7, <10 tiles) and n+0x08 = last enemy node seen.
=> UNIT +0x14/+0x18/+0x1c enemy near/mid/far, +0x20/+0x24/+0x28 friendly near/mid/far.
NOTE: corrects earlier notes (f24 'divisor', f20 'base strength'): see structs.md. 0x46a690 uses f28 on the TARGET node = its defenders.
