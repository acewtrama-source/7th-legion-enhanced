# 0x46b6e0 AI_AgeGuardPoints()   (tick case 7, every 8th tick per player)

[O] For each active guard point i (GP+8 != 0):
- Look through the unit lists of ALL players p = 1..N (head 0x5bbd50 + p*0x20). For each unit, find the FIRST guard point within 5 tiles (tile = obj.x>>21, GP.x>>5); if that is i, the point is "occupied".
- Occupied -> GP+8 = GP+0x1c (refresh lifetime).
- Not occupied -> GP+8 -= 1; when it reaches 0 the slot is free; log "AI Removed guard point" (if 0x4b8b20==1).
So a guard point lives while any unit (any owner) stays near it, otherwise its lifetime counts down in 8-tick steps from the value given to 0x46b820.
Note [I]: occupancy test is not limited to the AI's own or enemy units.
