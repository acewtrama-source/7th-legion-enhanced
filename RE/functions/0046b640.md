# 0x46b640 AI_GuardPointAttack()   (tick case 6)

[O] Walk the current player's unit list (head 0x5bbd50 + 0x5bcd74*0x20). Pick the FIRST unit with state (+0x38) == 2 (sent to a guard point), f28 (+0x28) > f1c (+0x1c) and f1c != 0. Call 0x469020(unit, 2) ("force group to attack" [I], string "AI Forcing group to attack" sits just before this function) and, if debug flag 0x4b8b20==1, log "AI Guard Point Attacking:<ent_id> <tileX>,<tileY>". Only one unit per call.
Meaning [I]: unit.f1c = enemy strength near the unit, unit.f28 = friendly strength near it (reinforce divides f1c by f28 for the "threat ratio"). Attack triggers when friendly > enemy and an enemy is present.
