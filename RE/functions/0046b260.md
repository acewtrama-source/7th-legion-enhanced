## Quirks to preserve
- Units are matched near ANY active GP, then the branch tests only whether it is the chosen one; the `local_1c==-1` path is unreachable.
- Recruiting adds to GP.A, the same field the loop compares against, so the loop likely runs through the whole unit list. Either intended or field roles are swapped. See open questions.
