Okumura LZSS decoder, N=4096 window, init filled with 0x20, write pos starts 0xfee, F=18, threshold 2. [O]
Input FILE* [0x5a38d4] (positioned after 'VCLZ'+int size header), output ptr [0x5a78e4] (advances). Window buf 0x5abd00.
Loop: flag byte (bit mask via local|0xff00), bit=1 -> copy literal byte; bit=0 -> read b1,b2: pos = b1 | (b2&0xf0)<<4, len = (b2&0xf)+3; copy len bytes from window[(pos+i)&0xfff]. Stops on EOF.
Container: 'V','C','L','Z' + int32 uncompressed size + LZSS stream (see LoadFile 0x4081a0). Reimpl: ~25 lines in any language; lets us unpack game assets.
