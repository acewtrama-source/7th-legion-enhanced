# 0x429cd0 Dist(short x1, short y1, short x2, short y2) -> int
[O] dx=|x2-x1|, dy=|y2-y1|; return max(dx,dy) + (min(dx,dy) >> 2). Cheap octagonal distance approximation (error ~ up to 12%). Used everywhere for tile distances. Arg order is (x1,y1,x2,y2): 0x469020 passes ENT x twice and no y (bug).
C: `int Dist(int x1,int y1,int x2,int y2){int dx=abs(x2-x1),dy=abs(y2-y1);int hi=dx>dy?dx:dy,lo=dx>dy?dy:dx;return hi+(lo>>2);}`
