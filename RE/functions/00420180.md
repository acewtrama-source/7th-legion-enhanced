# 0x420180 AllocBuildingSlot(int owner) -> slot or -1

- Range: owner's slice = [(owner-1)*(800/N), +800/N) where N = 0x834f88 (total players). If H (0x803c40) == 1 (single human) the range is 0..0x31e for everyone.
- Free = int at +0 (owner) == 0 and int at +0x0c == 0. The loop stops one short of the range end (`< start+len-1`).
- On success: sets 0x83a402 = 0x31e (highest index in use) and writes timestamp DAT_00803c48+10 into the record at +0x0c; returns slot.
- Failure returns 0xffff (low 16 bits) so callers test `(short)ret < 0`.
- Caller: 0x421d40 (CreateBuilding).
Note: 0x424c20 (CreateUnit) has the same slot-search pattern for units (180/N slice, 178 slots when H==1).
