## Quirks to preserve
- Mixes the parameter p (timers, tick counter) with global 0x5bcd74 (unit list heads, case-1 counter). Equal only if the caller sets the global to p first.
- Case-1 throttle: for level 0..15 the threshold is <= 1, so counter+1 >= threshold is always true and the throttle never skips. Matters only if 0x507484 can be out of range. [I]
- Ghidra shows `byte != 0xffffffff` for +0x4c; always true in C. Real compare is probably against 0xff. Verify in assembly around the 0x46c0xx range.
- Loop A orders with cmd 7 and all-minus-one args; same cmd appears in 0046b260 when target is -1,-1.
